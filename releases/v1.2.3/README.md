# aidisc v1.2.3 安装包

![cover](../../docs/cover.svg)

## 快速安装

1. 下载完整包 `aidisc-v1.2.3.zip`（对话附件或本目录解包）
2. 解压
3. Chrome 打开 `chrome://extensions`
4. 开启「开发者模式」
5. 「加载已解压的扩展程序」

## 从仓库解包（若已上传全部 p0–p9）

```bash
cd releases/v1.2.3
bash extract.sh
```
