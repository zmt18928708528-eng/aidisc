# aidisc 1.2.3

浏览器内多栏嵌入 AI 官网，按场景组织多人协作。

## 场景一览

1. **决策 → 执行 → 验收**（可多轮）
2. **三案并列 + 评论**
3. **2v2 辩论 + 评委**（正反交锋后评委裁决）
4. **队长分配 + 三人并行 + 合并**
5. **红队 / 蓝队安全评审**
6. **产品 + 设计 + 研发 + 测试**
7. **老师出题 / 学生作答 / 助教批改**
8. **投资人质疑 + 创始人答辩**（含追问与终答）

## 安装

1. Clone 或下载本仓库
2. Chrome 打开 `chrome://extensions`
3. 开启「开发者模式」
4. 「加载已解压的扩展程序」，选中本目录
5. 点工具栏图标打开 aidisc

## 使用

选场景 → 各栏下拉选模型并登录 → 输入议题 → 开始。

国内模型建议直连，国外模型（ChatGPT / Claude / Gemini / Grok）通常需要代理，建议代理工具开分流。
