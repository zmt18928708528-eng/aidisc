# aidisc

浏览器内多栏嵌入 AI 官网，按场景组织多人协作讨论。

**仓库：** https://github.com/zmt18928708528-eng/aidisc

## 推荐安装

请使用完整扩展包 `aidisc-v1.2.3.zip`（含全部 JS 与图标）：

1. 解压 zip
2. Chrome 打开 `chrome://extensions`
3. 开启「开发者模式」
4. 「加载已解压的扩展程序」

## 场景

1. 决策 → 执行 → 验收
2. 三案并列 + 评论
3. 2v2 辩论 + 评委
4. 队长分配 + 并行 + 合并
5. 红队 / 蓝队安全评审
6. 产品 + 设计 + 研发 + 测试
7. 老师出题 / 学生作答 / 助教批改
8. 投资人质疑 + 创始人答辩
